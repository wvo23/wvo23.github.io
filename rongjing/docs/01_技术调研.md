# 技术调研：换背景 + 人物自然融合（2026 最新）

## 一、市面软件调研

### 2. 真正"人物不变 + 自然融合"的路线
扩散模型整图重绘会换脸/变形。正确做法三步分离：
1. **抠图 Matting**：BiRefNet、ISNet、RMBG-2.0（发丝级）
2. **图像和谐化**：上海交大 libcom（Apache-2.0）、NVIDIA Harmonizer、PCT-Net、CDTNet、IC-Light（需 GPU）、Qwen-Image-Edit-2511
3. **免费 + 无 GPU + 人物不变**最优折中：开源抠图 + 经典图像和谐化（本项目路线）

## 二、为什么不用扩散模型重绘
扩散模型生成新背景时会重新采样人物像素 → 五官/发型变化；且需 GPU；本项目用"抠原始像素 + 只调光影"从根本保证人物不变。

## 三、融合方法取舍
| 方法 | 改人物内部像素 | 采用 |
|---|---|---|
| Reinhard 颜色迁移（LAB） | 否 | ✅ |
| 亮度/局部光照匹配 | 否 | ✅ |
| 接地阴影 | 否 | ✅ |
| 边缘去色边 + 羽化 | 仅边缘 | ✅ |
| 泊松融合 | 改梯度 | ⚠️ 默认关闭 |
| 扩散重绘/IC-Light | 改细节 | ❌ |
