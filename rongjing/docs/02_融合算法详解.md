# 融合算法详解（权威参考）

两处一致实现：Python `desktop-python/core/harmonize.py` 与 JS `web-pwa/src/fusion.js`。移植到 Swift 时互为参照，JS 版更贴近 Swift 逐像素写法。

## 1. 颜色空间转换
sRGB 线性化 → XYZ(D65) → LAB。OpenCV 兼容矩阵：
```
X = (0.412453R + 0.357580G + 0.180423B)/0.95047
Y = 0.212671R + 0.715160G + 0.072169B
Z = (0.019334R + 0.119193G + 0.950227B)/1.08883
f(t)= t>0.008856 ? cbrt(t) : 7.787t+16/116
L=116f(Y)-16; a=500(f(X)-f(Y)); b=200(f(Y)-f(Z))
```

## 2. 高光保护（最容易踩坑）
LAB 颜色迁移时 L 通道漂移限制：JS 版 ±9 且上限 92；Python 版 ±22 且上限 232（0-255 尺度）。不做会脸白成一片。

## 3. 步骤顺序
1. decontaminate_edges 去色边
2. reinhard_color_transfer 颜色迁移
3. match_luminance 亮度对齐
4. local_light_match 局部光照
5. [可选] poisson_blend（默认关闭）
6. add_contact_shadow 接地阴影
7. feather + composite 羽化合成

## 4. 阴影
光源方向 = 背景最亮区重心偏移；offX=-dx·前景宽·0.25；阴影来源为 mask 底部（t^6）；模糊后强度 clip 0.6。

## 5. 性能
640×960 逐像素：Python ~2s / JS ~1s / Swift 预计 ~0.3s；可分离高斯模糊是主要开销，用 vDSP 或 Metal 加速。

## 6. 验收基准
person.png 换到 room.png（偏暖）、office.png（偏冷）：五官不变、无白边、有阴影。
