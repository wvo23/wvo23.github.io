# 效果基准、素材来源与模型获取

## 1. 效果基准
户外男子（Pexels id=1680175）换到暖色室内→肤色偏暖黄；换到冷色办公室→偏冷蓝；五官发型表情完全一致，边缘无白边，有接地阴影。

## 2. 测试人像来源（Pexels 免费可商用）
```
https://images.pexels.com/photos/{id}/pexels-photo-{id}.jpeg?auto=compress&cs=tinysrgb&w=700
```
可用 id：1680175、997489、15127559。

## 3. AI 抠图模型获取（Python 版/CoreML 转换需要）
```
https://hf-mirror.com/x-Liola-x/isnet-general-use-onnx/resolve/main/isnet-general-use.onnx
```
下载后放 ~/.u2net/。代码已设 MODEL_CHECKSUM_DISABLED=1 跳过 MD5 校验。

## 4. Mac 原生版不需要模型
用 Apple Vision 抠图则完全免模型。仅追求极致发丝质量时才需转 CoreML：
```python
import coremltools as ct
model = ct.converters.onnx.convert(model='isnet-general-use.onnx', minimum_deployment_target=ct.target.macOS13)
model.save('ISNet.mlpackage')
```
.mlpackage 已加入 .gitignore。
